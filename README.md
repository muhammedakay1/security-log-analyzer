# Security Log Analyzer

A Python-based security tool that analyzes log files to detect suspicious login activity and potential brute-force attacks.

## Features

- Detects failed login attempts
- Identifies suspicious IP addresses and users
- Detects potential brute-force attacks
- Generates a JSON report
- Logs analysis activity

## Requirements

- Python 3
- No external libraries required

## Usage

```bash
python3 main.py -f logs/sample.log
